# 多基金代码支持说明

## 概述

程序已成功修改，现在支持处理多个基金代码。您可以通过以下方式指定要处理的基金代码：

1. **命令行参数**：直接指定基金代码列表
2. **配置文件**：在config.json中配置基金代码列表
3. **单个基金**：处理单个基金代码

## 使用方法

### 1. 使用命令行参数指定多个基金代码

```bash
# 处理多个基金代码
python main.py --fund-codes 005538 015790 000001

# 指定开始日期和数据目录
python main.py --fund-codes 005538 015790 --start-date 2023-01-01 --data-dir stock_data
```

### 2. 使用配置文件

在`config.json`文件中配置基金代码列表：

```json
{
  "fund_codes": ["005538", "015790", "000001", "000002"],
  "start_date": "2021-01-01",
  "data_dir": "stock_data"
}
```

然后运行：
```bash
python main.py
```

### 3. 处理单个基金代码

```bash
# 处理单个基金
python main.py --single-fund 000001

# 处理单个基金并指定开始日期
python main.py --single-fund 000001 --start-date 2024-01-01
```

### 4. 查看帮助信息

```bash
python main.py --help
```

## 程序功能

修改后的程序具有以下特点：

### 1. **批量处理**
- 支持同时处理多个基金代码
- 每个基金独立处理，互不影响
- 提供总体汇总报告

### 2. **灵活的配置**
- 命令行参数优先级最高
- 支持配置文件
- 支持默认值

### 3. **详细的日志**
- 每个基金的处理过程都有独立日志
- 显示处理进度
- 错误信息清晰

### 4. **结果汇总**
- 显示总基金数、成功数、失败数
- 汇总所有基金的股票统计
- 列出处理失败的基金及原因

## 输出文件

程序会为每个基金的持仓股票生成以下文件：

1. **股票K线数据**：`data/stock_data/{股票代码}_kline.csv`
2. **技术指标数据**：`data/{股票代码}_with_indicators.csv`
3. **信号判断结果**：`data/{股票代码}_signals.csv`

## 注意事项

1. **网络请求**：程序会从网络获取基金持仓数据和股票K线数据，请确保网络连接正常
2. **数据缓存**：已下载的数据会保存在本地，下次运行时优先使用本地数据
3. **错误处理**：单个基金处理失败不会影响其他基金的处理
4. **进度显示**：使用tqdm显示处理进度，直观了解处理状态

## 故障排除

### 常见问题

1. **"不支持的周期: d"错误**
   - 已修复：将`period='d'`改为`period='daily'`

2. **基金持仓数据为空**
   - 检查基金代码是否正确
   - 检查网络连接
   - 确认基金是否有持仓数据

3. **股票数据获取失败**
   - 检查股票代码格式
   - 确认股票是否在A股市场
   - 检查网络连接

### 日志文件

程序运行日志保存在`ak_fund.log`文件中，可以查看详细处理过程。

## 版本更新说明

### 主要修改

1. **重构main函数**：将单个基金处理逻辑提取为`process_single_fund`函数
2. **添加命令行参数解析**：支持多种方式指定基金代码
3. **添加配置文件支持**：支持从JSON文件读取配置
4. **改进错误处理**：单个基金失败不影响其他基金
5. **增强日志输出**：提供更详细的处理信息

### 向后兼容性

- 原有的`FUND_CODE`变量已改为`FUND_CODES`列表
- 支持原有的单个基金处理方式（通过`--single-fund`参数）
- 默认配置与原有程序兼容
